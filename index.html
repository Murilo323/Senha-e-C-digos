O que acontece por trás?

Este projeto usa AES-GCM, um algoritmo moderno de criptografia simétrica disponível na Web Crypto API.

01
Preparação

O navegador transforma o texto em bytes usando UTF-8, uma forma de representar caracteres digitalmente.

02
Chave e nonce

É criada uma chave AES de 256 bits e um nonce aleatório de 12 bytes. A mesma chave será usada para reverter o processo.

03
Criptografia

O AES-GCM combina os dados com a chave e o nonce. O resultado fica ilegível sem a chave correta e inclui uma verificação de integridade.

04
Codificação Base64

Os bytes criptografados são representados como caracteres para facilitar a exibição e a cópia. Base64 não é criptografia.

05
Descriptografia

O navegador usa a chave guardada temporariamente e o nonce para validar e recuperar os bytes originais. Depois, converte-os de volta para texto.

Importante: esta é uma demonstração educativa. A chave fica apenas na memória desta página e é perdida ao recarregar ou fechar a aba. Não use o site para proteger senhas reais ou informações confidenciais.
